关于我们

FCBSS 是一款面向 Windows 平台的轻量级安全辅助工具，专注于本地文件扫描与行为检查。

本项目由个人开发者以“纯净、可控、低资源占用”为设计目标维护，完全不捆绑任何附加软件。

技术栈：
· 开发环境：Dev-C++ 5.11
· 核心语言：C++98
· 底层依赖：原生 Windows API (windows.h)
